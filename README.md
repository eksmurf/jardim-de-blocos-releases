# Jardim de Blocos

Puzzle para Android: encaixe peças, complete linhas e cultive um pequeno jardim.

## Download

Baixe **Jardim-de-Blocos.apk** na [versão mais recente](https://github.com/eksmurf/jardim-de-blocos-releases/releases/latest). Android 7 ou superior; ARM32 e ARM64. É um protótipo em teste, distribuído fora da Play Store.

O código-fonte é mantido em repositório privado. Este repositório contém apenas documentação pública e versões para download. O jogo usa Godot; avisos de terceiros acompanham o APK.

## Atualizações

A partir da versão 0.1.2, habilite **Atualizações → Verificar e baixar ao abrir**. O jogo consulta este repositório, baixa uma versão mais recente e confere seu checksum. A instalação exige a confirmação do Android. Quem está na 0.1.1 precisa instalar a 0.1.2 manualmente uma vez, por cima da anterior.

Atualizar com o mesmo pacote/assinatura preserva os dados locais; não desinstale para atualizar. O jogo continua disponível sem internet. Não há anúncios, compras ou telemetria nesta versão.

Leia a [política de privacidade](PRIVACIDADE.md). Problemas podem ser relatados nas [issues](https://github.com/eksmurf/jardim-de-blocos-releases/issues), sem dados pessoais sensíveis.
